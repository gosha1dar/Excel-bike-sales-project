# Bike Sales Dashboard (Excel)

## About the Project

In this project, I worked with a bike sales dataset in Microsoft Excel.
The goal was to clean the raw data, analyze customer purchasing behavior, and create an interactive dashboard for easier business insights.

The project includes the full workflow:

* raw data cleaning
* data transformation
* pivot table analysis
* dashboard creation

---

## Dataset

The dataset contains customer information such as:

* income
* age
* gender
* occupation
* commute distance
* bike purchase status

---

## What I Did

### Data Cleaning

* checked and organized raw data
* improved readability of columns and values
* prepared the dataset for analysis

### Pivot Tables

Created pivot tables to analyze:

* average income by bike purchase
* purchase behavior by gender
* customer commute distance
* demographic trends

### Dashboard

Built an interactive dashboard in Excel using:

* charts
* slicers
* pivot charts
* filters

The dashboard makes it easier to explore trends and compare customer groups.
